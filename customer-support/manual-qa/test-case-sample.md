## Testing Process

For each test case, I:

1. Identified the functionality to be tested.
2. Defined the expected behaviour.
3. Executed the test manually.
4. Compared the actual result against the expected result.
5. Recorded the result as Pass or Fail.
6. Documented any issue discovered during testing.
7. Retested functionality after fixes when applicable.
