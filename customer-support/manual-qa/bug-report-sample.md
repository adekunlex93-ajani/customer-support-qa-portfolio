## Bug Report

### Bug ID

BUG-001

### Title

Product category link does not open the expected page

### Severity

Medium

### Priority

Medium

### Environment

* Application Type: Web Application
* Browser: Google Chrome
* Testing Type: Manual Functional Testing
* Platform: Desktop

### Preconditions

The website is accessible and the product category navigation menu is available.

### Steps to Reproduce

1. Open the website.
2. Navigate to the product category section.
3. Click **Bottled Water**.
4. Observe the page that loads.

### Expected Result

The **Bottled Water** category should open the correct product category page and display the relevant products or content.

### Actual Result

The link does not open the expected product category page.

### Impact

Users may be unable to access the relevant product information through the category navigation, which can affect website usability and customer experience.

### Evidence

Screenshots or screen recordings would normally be attached to the bug report to provide evidence of the issue.

### Suggested Investigation

* Verify the category link URL.
* Check whether the destination page is available.
* Confirm that the navigation link is correctly configured.
* Retest the functionality after the issue has been fixed.

### Status

Open

## Bug Reporting Process

My typical manual QA defect-reporting process is:

**Identify issue → Reproduce issue → Document steps → Record expected result → Record actual result → Assess impact → Attach evidence → Report → Retest after fix → Close**
